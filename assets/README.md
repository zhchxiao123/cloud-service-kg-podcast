# 通用素材

本目录存放全系列通用的品牌素材、字体、片头片尾等。

## 目录规划

- `fonts/`：字体文件与使用说明（Noto Sans SC / Noto CJK）
- `logo/`：系列 Logo 源文件
- `intro-outro/`：片头片尾视频/音频
- `templates/`：PPT / Marp / 封面模板
- `thumbnails/`：封面示例

## 品牌规范

- 主色调：深蓝 `#1E3A5F` + 橙 `#F4A261`
- 字体：Noto Sans SC / Noto CJK（见 [[podcast-video-font-fallback]] 记忆）
- 封面必须包含：系列 Logo、集数、标题、频道名
