# EP01 | 本体到底解决什么问题？

## 学习目标

让观众在 10 分钟内建立学习动机，理解“数据孤岛、语义不一致、LLM 幻觉”三个痛点如何通过本体工程缓解。

## 核心知识点

- 数据孤岛：同一实体在不同系统里的不同名字。
- 语义不一致：同一字段在不同表里含义不同。
- LLM 幻觉：大模型缺乏结构化领域知识，会编造关系或属性。
- 本体的价值：提供“共享概念化”的显式、形式化规格说明。

## 演示素材

- 对比图：Excel 表格 vs 图结构 vs 加了 OWL 约束的图。
- 向量 RAG vs 知识图谱回答示例。
