# 云服务本体术语表

> 版本：v0.1  
> 状态：EP04 建模基线  
> 范围：支持 EP03 的 Must-have Competency Questions。

## 核心术语

| 本体名称 | 中文标签 | 类型 | 定义 | 来源 CQ |
|---|---|---|---|---|
| `CloudService` | 云服务 | 类 | 云服务商通过公开产品目录提供的可识别服务。 | CQ-01、CQ-02、CQ-03 |
| `ComputeService` | 计算服务 | 类 | 提供虚拟机、容器或加速计算能力的云服务。 | CQ-01 |
| `StorageService` | 存储服务 | 类 | 提供对象、块或文件数据持久化能力的云服务。 | CQ-02 |
| `DatabaseService` | 数据库服务 | 类 | 提供数据库部署、运行或托管能力的云服务。 | CQ-03 |
| `CloudProvider` | 云服务商 | 类 | 发布并运营一个或多个云服务的组织。 | CQ-01、CQ-02、CQ-03 |
| `Region` | 区域 | 类 | 云服务商用于描述服务可用位置的命名地理范围。 | CQ-01、CQ-02 |
| `AccessTier` | 访问层级 | 类 | 对象存储按访问频率、延迟或价格组织的服务层级。 | CQ-02 |
| `ManagementModel` | 托管模式 | 类 | 描述数据库基础设施和运维责任如何分配的模式。 | CQ-03 |
| `hasProvider` | 由……提供 | 对象属性 | 把云服务连接到提供该服务的云服务商。 | CQ-01、CQ-02、CQ-03 |
| `hasRegion` | 可用区域 | 对象属性 | 把云服务连接到其可用的云区域。 | CQ-01、CQ-02 |
| `hasAccessTier` | 访问层级 | 对象属性 | 把存储服务连接到它提供的访问层级。 | CQ-02 |
| `hasManagementModel` | 托管模式 | 对象属性 | 把数据库服务连接到其托管模式。 | CQ-03 |
| `hasGPU` | 支持 GPU | 数据属性 | 表示计算服务是否公开提供 GPU 计算能力。 | CQ-01 |
| `monthlyPriceUsd` | 月费（美元） | 数据属性 | 统一口径下以美元表示的月度参考价格。 | CQ-05 |
| `dataSource` | 数据来源 | 注释属性 | 记录一条术语或事实的公开证据地址。 | CQ-04、CQ-06 |
| `lastUpdated` | 最后更新 | 注释属性 | 记录术语或事实最近核验的日期。 | CQ-04、CQ-06 |

## 粒度决定

- `ComputeService` 是类，表示一组计算服务。
- `AWS_EC2`、`Azure_VM` 是个体，表示可枚举的产品级服务。
- 具体实例系列或 SKU 暂不进入 v0.1；当价格 CQ 需要统一规格比较时再扩展。
- 产品名称不能仅凭书写形式判断为类或个体，最终选择由 CQ 的答案粒度决定。
